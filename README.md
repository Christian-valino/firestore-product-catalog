# FireStore Product Catalog — NoSQL Database

Projeto desenvolvido para a **FATEC Cotia** abordando a modelagem, implementação e operação de um banco de dados NoSQL focado em um catálogo de produtos[cite: 2].

## 📌 Sobre o Projeto
O sistema permite realizar todas as operações de **CRUD** (Create, Read, Update, Delete) com persistência em tempo real no banco de dados não relacional Firebase Firestore[cite: 2]. Conta com uma interface web rodando diretamente no navegador e uma rotina de integração em Python[cite: 2, 3].

## 🛠️ Tecnologias Utilizadas
- **Frontend / Web:** HTML5, CSS3 e JavaScript (Vanilla)[cite: 2]
- **Script backend / Automação:** Python 3 (SDK `firebase-admin`)[cite: 3]
- **Banco de Dados:** Firebase Firestore (NoSQL Document Store)[cite: 2]

## 📋 Funcionalidades
- **Create:** Cadastro de produtos com nome, preço, categoria, estoque e descrição[cite: 2, 3, 4].
- **Read:** Listagem completa, busca em tempo real e filtros por categoria[cite: 2, 3, 4].
- **Update:** Edição de dados e estoque de itens cadastrados[cite: 2, 3, 4].
- **Delete:** Remoção de produtos da coleção[cite: 2, 3, 4].
- **Dashboard Web:** Painel estático com métricas de total de itens, categorias e estoque global[cite: 4].
