# FireStore Product Catalog — NoSQL Database

Projeto desenvolvido para a **FATEC Cotia** abordando a modelagem, implementação e operação de um banco de dados NoSQL focado em um catálogo de produtos.

## 📌 Sobre o Projeto
O sistema permite realizar todas as operações de **CRUD** (Create, Read, Update, Delete) com persistência em tempo real no banco de dados não relacional Firebase Firestore. Conta com uma interface web rodando diretamente no navegador e uma rotina de integração em Python.

## 🛠️ Tecnologias Utilizadas
- **Frontend / Web:** HTML5, CSS3 e JavaScript (Vanilla)
- **Script backend / Automação:** Python 3 (SDK `firebase-admin`)
- **Banco de Dados:** Firebase Firestore (NoSQL Document Store)

## 📋 Funcionalidades
- **Create:** Cadastro de produtos com nome, preço, categoria, estoque e descrição.
- **Read:** Listagem completa, busca em tempo real e filtros por categoria.
- **Update:** Edição de dados e estoque de itens cadastrados.
- **Delete:** Remoção de produtos da coleção.
- **Dashboard Web:** Painel estático com métricas de total de itens, categorias e estoque global.
